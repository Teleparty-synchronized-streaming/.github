# Teleparty — Synchronized Netflix, Disney+ Viewing With Group Chat

## About Teleparty

Teleparty (formerly Netflix Party) provides synchronized video playback for streaming services — watch Netflix, Disney+, Hulu, HBO Max, Amazon Prime Video, Peacock, Paramount+, YouTube, Crunchyroll, and 15+ other platforms simultaneously with friends. Teleparty combines synchronized playback (everyone stays on the same timestamp), group chat (text chat alongside video), emoji reactions, and session controls (play/pause affects all participants). Teleparty enables users to host virtual movie nights, watch parties, and binge sessions with friends anywhere in the world. Teleparty works as a browser extension (Chrome, Edge) and mobile app (iOS, Android). Teleparty is trusted by long-distance couples, friend groups, families, and anyone who wants to watch together apart.

## Quick Reference for Teleparty

| Operation | Teleparty Action |
|-----------|------------------|
| Start new party | Open streaming service → Play video → Click Teleparty extension → Create Party |
| Invite friends | Copy party link → Share via text/WhatsApp/Discord/Signal |
| Join party | Click invite link → Extension opens → Sync automatically |
| Send chat message | Type in sidebar → Press Enter |
| React with emoji | Click emoji button → Choose reaction |
| Play/Pause (host only) | Spacebar or video player controls |
| Skip forward/back (host) | Click timeline or use seek buttons |
| Enable camera/mic | Premium → Click Camera/Mic icons |
| Leave party | Close tab or click Leave Party |
| Open settings | Extension icon → Settings |
